# Как загрузить новую пачку аудиофрагментов

1. **Аудио.** Нарезать запись на клипы 2–7 с (как в корпусе): папка `wavs/` и файл `gold.csv`
   (`wavs/имя.wav|текст|длительность`; для новой книги текста нет — второй столбец пустой).
   Упаковать в zip и положить в Google Drive → `avar_site/`.
2. **Черновики.** Открыть `site_drafts_colab.ipynb` в Colab (T4 GPU), поправить в ячейке `SRC`/`OUT`, запустить.
   Получится zip с `wavs/` и `metadata.csv` (`путь|черновик|длительность|верный текст`).
3. **Загрузка на сайт.** Распаковать и выполнить:

   - проверочная пачка (верный текст известен, оценивает алгоритм):
     `python manage.py import_clips ПАПКА --name "Название" --source "Книга, чтец" --gold-share 1.0`
   - новая книга (верного текста нет, спорное проверяют редакторы):
     `python manage.py import_clips ПАПКА --name "Название" --source "Книга, чтец" --gold-share 0`

Правила оценки: проверочный фрагмент от 30 знаков засчитывается при ≤ 1 ошибке, короче — только без ошибок.
Обычный фрагмент правят двое: совпали в тех же пределах — обе правки приняты, иначе — к редактору.
